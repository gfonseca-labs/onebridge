# NYC study source tables

Reviewed tables for the NYC study, read by `onebridge prepare`. Formats are
described in [docs/DATA.md](../../docs/DATA.md#reviewed-tables).

These tables are derived from OpenStreetMap data (2026-10-24 snapshot), and
the hospital registry from New York State and New Jersey facility lists. They
are © OpenStreetMap contributors and available under the Open Database
License 1.0 (https://opendatacommons.org/licenses/odbl/1-0/); see
[NOTICE.md](../../NOTICE.md).
