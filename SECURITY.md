# Security reporting

OneBridge is a local research tool. Use trusted datasets, input directories
and Python environments; outputs are not operational emergency-routing advice.

For a suspected vulnerability, use
[GitHub private reporting](https://github.com/gfonseca-labs/onebridge/security/advisories)
if available. If it is unavailable, open an issue requesting a private contact
method without including exploit details or confidential data. Include the
affected commit or version, platform, and a minimal reproduction with public
or synthetic inputs. There is no guaranteed response time or support period.

Report ordinary reproducibility or modeling errors in
[issues](https://github.com/gfonseca-labs/onebridge/issues). State the
configuration and distinguish a software defect from a data assumption.
See [architecture and limitations](docs/ARCHITECTURE.md).
